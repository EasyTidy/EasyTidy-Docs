本页汇总 EasyTidy Pro 使用过程中较常见的问题。第一次使用时，建议先阅读[快速开始](/zh-cn/getting-started/)；安装、便携模式和卸载说明请参阅[安装指南](/zh-cn/install/)。

## 安装与启动

### EasyTidy Pro 支持哪些系统？

EasyTidy Pro 支持 64 位 Windows 11，以及 Windows 10 v2004（内部版本 19041）或更高版本。当前发布包面向 x64 架构。

标准安装包需要 .NET 10 Desktop Runtime 和 ASP.NET Core Runtime 10，安装程序会在缺少依赖时提供引导；自包含安装包和便携包已经内置运行时。具体选择方式请参阅[下载页面](/zh-cn/download/)。

### 标准安装包、自包含安装包和便携包应该选哪个？

- **标准安装包**：适合大多数用户，体积较小；缺少运行时时按安装向导补充即可。
- **自包含安装包**：已内置所需运行时，体积较大，适合新系统或不希望单独安装运行时的环境。
- **便携包**：无需安装，解压后运行 `EasyTidyPro.exe`；请放在当前用户可写的目录，不要放在 `Program Files`、Windows 系统目录或直接在压缩包内运行。

### 点击 <span class="fluent-icon fluent-icon--dismiss" aria-hidden="true"></span> 关闭按钮后，为什么程序仍在运行？

关闭主窗口时，EasyTidy Pro 可以继续在系统托盘运行，以便执行文件监控、定时任务和其他自动流程。需要彻底退出时，请右键通知区域中的 EasyTidy Pro 图标并选择“退出”。

如果没有看到图标，请先展开 Windows 通知区域中的隐藏图标；也可以将图标拖到可见区域，方便以后恢复窗口或退出程序。

### 下载或运行时被 Windows Defender、SmartScreen 或其他安全软件拦截怎么办？

请先确认安装包来自[官网下载页](/zh-cn/download/)或 [GitHub Releases](https://github.com/EasyTidy/EasyTidy-Releases/releases)，再使用发布页提供的 `checksums.txt` 校验 SHA-256：

```powershell
Get-FileHash .\EasyTidyPro_win-x64_Setup.exe -Algorithm SHA256
```

少数版本可能触发未知发布者提示或名称带 `!ml` 的机器学习启发式检测。不要直接关闭安全软件，也不要运行来源或哈希无法确认的文件。确认来源与哈希无误后，可以先更新病毒库并复检；仍被拦截时，请将检测名称、软件版本和安装包哈希提交到[问题反馈](https://github.com/EasyTidy/EasyTidy-Releases/issues)。

## 配置与升级

### 配置、任务和数据库保存在哪里？

正式版默认使用以下目录：

```text
%APPDATA%\EasyTidyPro
```

可以在文件资源管理器地址栏输入 `%APPDATA%\EasyTidyPro` 直接打开。任务、设置、集成配置和数据库都属于用户数据，排查问题或迁移前请先备份；日志建议从应用的“运行日志”页面打开日志目录。

### 如何使用便携配置？为什么切换后原来的任务不见了？

将便携包解压到可写目录，并在 `EasyTidyPro.exe` 同级创建名为 `portable_config` 的文件夹，重新启动后，应用会改用该目录保存配置和数据库：

```text
EasyTidyPro\
├── EasyTidyPro.exe
└── portable_config\
```

系统配置与便携配置是两套独立数据。直接新建或删除 `portable_config` 不会自动合并已有数据，因此切换后看到空任务列表通常不代表数据丢失。优先使用 **设置 → 常规设置** 中的便携配置切换功能，并在提示时选择复制现有配置；手动迁移前应先退出程序并保留原目录备份。

### 升级或重装会删除任务和设置吗？

正常覆盖升级不会主动清除用户数据，但重要环境升级前仍建议先停止正在执行的任务，并在 **设置 → 备份与还原** 创建备份。不要在应用运行时直接复制数据库文件；卸载后手动删除 `%APPDATA%\EasyTidyPro`，或删除包含 `portable_config` 的整个便携目录，才会一并移除对应数据。

## 规则与自动运行

### 为什么预览中没有文件，或只匹配到部分文件？

按以下顺序检查：

1. 源文件夹是否正确、当前可访问，文件是否位于未包含的子文件夹中。
2. 文件匹配规则是否使用正确的通配符；例如 `*.jpg;*.png`，多个规则使用分号或竖线分隔。
3. 文件大小、日期、属性、正则表达式或组合条件是否又排除了这些文件。
4. 任务是否已启用，文件是否正被其他程序占用，当前账户是否有读取权限。
5. 在“运行日志”中查看跳过或失败的具体原因。

规则语法和示例请参阅[配置规则](/zh-cn/guide/rules/)。

### 为什么提示规则无效？

普通文件匹配使用通配符，不是完整的正则表达式。例如，匹配 PDF 应填写 `*.pdf`，匹配多种格式可填写 `*.jpg;*.png;*.webp`。需要正则表达式时，请使用对应的正则条件或重命名参数，不要直接把正则写进普通通配符输入框。

还应检查分隔符、括号和模板参数是否完整。可先选择输入框旁的预设规则，再逐项修改；仍无法保存时，请附上已脱敏的规则和错误提示进行反馈。

### 为什么只有部分文件被移动、复制或重命名？

最常见的原因是目标位置已存在同名文件，而当前冲突策略设置为“跳过”。请检查任务自身的冲突处理设置以及全局冲突策略，并根据需要选择覆盖或自动重命名。覆盖可能造成数据丢失，修改后应重新预览并先用测试文件验证。

其他常见原因包括文件被占用、路径不可用、权限不足、文件在扫描后已发生变化，或后续筛选条件将其排除。具体原因以“运行日志”中的记录为准。

### 预览会修改文件吗？可以跳过预览吗？

预览只计算匹配结果和文件流向，不会执行移动、复制、重命名或删除。首次创建任务、修改规则或处理重要目录后，都应先检查预览中的来源、目标和文件数量。

部分场景允许在设置中减少确认步骤，但不建议对删除、覆盖、批量移动或批量重命名等操作跳过预览。

### 为什么自动任务没有按预期执行？

请确认任务和对应触发器均已启用并保存，EasyTidy Pro 仍在运行，源目录在触发时可访问。文件变更触发还应设置适当延迟，避免文件尚未写入完成就开始处理；计划或 CRON 触发则需要检查系统时间、表达式和下一次运行时间。

如果程序已经彻底退出，依赖应用进程的文件监控和定时触发不会继续工作。详细配置方式请参阅[自动化配置](/zh-cn/guide/automation/)，失败原因可在“运行日志”中查看。

### 为什么文件监控会反复触发同一个任务？

通常是目标文件夹位于被监控的源文件夹内，任务生成或移动文件后又触发了新的文件变更。请把目标目录移到监控范围之外，或通过排除规则明确忽略目标目录和临时文件；同时设置适当的触发延迟，避免短时间内重复处理。

## 数据安全与隐私

### 整理错了可以撤销吗？

移动、复制、重命名等受支持的本地操作会在满足条件时生成撤销记录，可通过 <span class="fluent-icon fluent-icon--undo" aria-hidden="true"></span> **撤销** 入口或 `Ctrl+Z` 恢复最近一次操作。能否撤销还取决于操作类型、备份是否仍存在以及撤销记录的保留时间。

云端上传、外部程序、部分转换或已过期记录等操作可能无法撤销。只有在界面明确显示可撤销记录时才应依赖该功能；撤销不能替代独立备份。

### EasyTidy Pro 会上传我的文件吗？

基础规则匹配、预览和本地文件操作默认在当前设备完成。只有在主动启用并配置在线 AI、MinerU 云端 OCR、WebDAV、S3、百度网盘、123 云盘或其他远程服务时，相关文件、文本、图片、元数据或提示词才可能发送给对应服务商。

处理敏感文件前，请检查所用功能的配置和第三方服务条款。希望完全离线使用时，不要启用在线 AI、云端 OCR、云存储及其他远程集成；更新检查和授权验证也可能访问网络。

### 免费版和 Pro 版有什么区别？

基础能力可以直接使用，部分高级流程、AI、集成或增强功能需要 EasyTidy Pro 权限。界面中的 **Pro** 标识表示该功能受授权策略限制；无法使用带标识的功能时，请先检查当前授权状态，而不是重复安装程序。

## 故障排查与反馈

### 程序启动失败、任务报错或界面结果异常时，应该提供哪些信息？

先重启应用并用少量测试文件复现，然后在“运行日志”页面查看错误并打开日志目录。提交问题前请准备：

- EasyTidy Pro 完整版本号和安装包类型；
- Windows 版本与系统架构；
- 可稳定复现的操作步骤、预期结果和实际结果；
- 相关日志与截图；
- 已脱敏的规则、源目录结构和触发方式。

请先移除日志或截图中的私人路径、文件名、Token、密钥和个人数据，再到 [EasyTidy Releases Issues](https://github.com/EasyTidy/EasyTidy-Releases/issues) 提交问题。
