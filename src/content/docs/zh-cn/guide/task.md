“整理任务”用于定义一条可重复执行的文件处理规则：**从哪些位置查找文件、匹配哪些文件、执行什么操作，以及把结果放到哪里**。任务创建后可以手动运行，也可以在[自动运行](/zh-cn/guide/automation/)中添加文件变化、启动、定期或 CRON 触发器。

:::caution[先用测试目录验证]
移动、重命名、覆盖、删除、解密等操作会直接改变文件。第一次配置时请使用少量测试文件，并在执行前核对预览结果。重要文件应保留独立备份。
:::

## 快速开始

只需要完成一次简单的移动或复制时，推荐从快速创建开始：

1. 进入 **文件整理 → 整理任务**。
2. 打开 <span class="fluent-icon fluent-icon--task-add" aria-hidden="true"></span> **新建任务** 右侧的 <span class="fluent-icon fluent-icon--chevron-down" aria-hidden="true"></span> **下拉菜单**，选择 <span class="fluent-icon fluent-icon--flash" aria-hidden="true"></span> **快速创建**。
3. 选择源目录。可以直接选择“下载”“桌面”“图片”，也可以浏览或拖入其他文件夹。
4. 选择要整理的文件类型；需要自定义时填写文件匹配规则。
5. 填写任务名称，选择 **移动** 或 **复制**，再选择目标目录。
6. 点击 <span class="fluent-icon fluent-icon--eye" aria-hidden="true"></span> **创建并预览**。系统先保存任务并统计匹配文件，不会在预览阶段修改文件。
7. 确认匹配数量和操作方式后执行。执行完成后，可按提示配置自动运行。

## 完整创建任务

打开 <span class="fluent-icon fluent-icon--task-add" aria-hidden="true"></span> **新建任务 → 直接创建**，按下面的顺序配置。

### 1. 填写名称和分组

- **任务名称**：建议同时写清对象和动作，例如“移动下载目录中的 PDF”。
- **任务分组**：从下拉列表中选择已有分组。新建任务默认归入系统内置的“未分组”，不需要先创建或手动输入分组名。

需要新增、重命名或删除分组时，请回到整理任务列表，打开顶部的分组选择器并点击 **分组管理**。分组名称不能重复；创建或重命名时如果与现有名称相同，应用会提示修改。

分组用于筛选和批量执行，不代表任务之间存在依赖关系。需要分支、条件、步骤链或失败策略时，应改用[高级流程](/zh-cn/guide/workflow/)。

### 2. 选择操作方式

当前整理任务支持以下操作：

| 类别 | 操作 | 用途 |
| --- | --- | --- |
| 基础整理 | 移动、复制、重命名 | 调整文件位置或名称 |
| 标签 | 添加标签、移除标签 | 管理文件标签及颜色 |
| 压缩与转换 | 压缩、解压、格式转换 | 生成压缩包、提取内容或转换文件格式 |
| 安全 | 加密、解密、文件伪装 | 保护或还原文件，或使用载体生成可正常打开的伪装文件 |
| 智能处理 | AI 分类、AI 总结、重复文件整理 | 使用模型生成分类计划、摘要，或识别重复文件 |
| 链接与传输 | 文件快照、硬链接、软链接、云端传输、运行外部程序 | 生成目录快照、创建链接、连接云端节点或调用程序/脚本 |
| 清理 | 移至回收站、永久删除 | 清理不再需要的文件 |
| 数据提取 | 提取结构化数据 | 从文件内容中提取指定字段并输出结构化结果，例如：Excel |

选择操作后，编辑器会显示对应参数。例如重命名会显示模板设置，压缩会显示格式和压缩参数，去重会显示识别策略与保留动作，云端传输会显示方向和云端节点。文件伪装等 Pro 专属操作会在操作方式列表中显示 **PRO** 标记；其他高级能力的授权状态也应以应用内提示为准。

:::caution[回收站与删除不同]
“移至回收站”通常可以从 Windows 回收站恢复；“永久删除”不能依靠回收站恢复。执行清理任务前务必预览并检查源目录。
:::

### 3. 配置文件匹配规则

常见写法如下：

| 规则 | 匹配内容 |
| --- | --- |
| `*` | 所有文件 |
| `*.pdf` | PDF 文件 |
| `*发票*` | 文件名中包含“发票”的文件 |
| `*.jpg;*.png;*.webp` | JPG、PNG 或 WebP 图片 |
| `#` | 未被更高优先级任务处理的其他文件 |

多个基础规则可使用半角分号 `;` 或竖线 `|` 分隔。需要复杂文件名判断时，可以勾选 **视为正则表达式**；需要按大小、时间、属性或内容筛选时，打开 <span class="fluent-icon fluent-icon--filter" aria-hidden="true"></span> **筛选条件**。详细语法和示例请参阅[配置规则](/zh-cn/guide/rules/)和[筛选条件](/zh-cn/guide/filter/)。

:::note[文件规则与文件夹规则]
普通文件规则和文件夹规则不能混在同一任务中。文件夹规则包括 `**`、`##` 以及以 `=` 开头的完整文件夹名匹配；编辑器检测到混用时会保留一种类型并给出提示。
:::

编辑器中的 **智能规则助手** 可以根据自然语言生成规则；规则编辑器还可能提供视觉样板、文本标签和深度语义理解。使用这些功能前，请检查模型、组件和 Pro 授权状态，并在预览中核对实际命中结果。

### 4. 设置源位置和目标位置

- **源位置**：待扫描的文件或文件夹。可以点击 <span class="fluent-icon fluent-icon--folder-open" aria-hidden="true"></span> **文件夹**按钮选择，也可以把文件/文件夹拖入输入框。
- **多个源位置**：使用选择器添加多个位置后，应用会以半角分号保存并逐个扫描。
- **路径别名**：点击路径输入框旁的 <span class="fluent-icon fluent-icon--database" aria-hidden="true"></span> **路径别名**按钮，可使用 `%Downloads%`、`%Documents%` 等内置别名或自定义别名，便于在不同设备间分享规则。
- **目标位置**：移动、复制、重命名、压缩等操作的输出位置。删除、回收站、标签、格式转换、结构化提取等操作会根据自身参数隐藏普通目标位置。

是否扫描子文件夹取决于 **设置 → 常规设置** 中的子文件夹选项。源位置和目标位置同时留空时，编辑器会提示风险；不要依赖空路径的隐式行为，建议始终明确选择需要处理的位置。

:::caution[避免源目标循环]
自动运行时，不要把目标文件夹放在受监控源文件夹内部。复制、解压、摘要或转换产生的新文件可能再次触发同一任务，形成重复处理。
:::

### 5. 完成操作专用参数

不同操作的参数差异较大，以下几项最容易影响结果：

- **移动/复制的同名文件处理**：根据界面选择跳过、覆盖、仅在源文件较新或大小不同时覆盖、自动追加序号/日期，或使用 Git 版本控制。覆盖策略会影响手动运行时是否强制显示预览。
- **重命名**：使用模板组合原文件名、父文件夹、计数器、日期、随机字符串或照片元数据。先用少量文件验证扩展名和计数器结果。
- **压缩/解压/加密/解密**：检查格式、密码、输出位置和同名文件策略。密码遗失可能导致数据无法恢复。
- **重复文件整理**：先选择识别策略，再选择保留、标记、移动或删除动作。大目录首次扫描可能耗时较长。
- **AI 分类**：不需要填写普通匹配规则，运行时会先生成分类计划并提供计划预览；模型提供方可能会接收文件信息或内容。
- **云端传输**：上传时使用本地源位置，取回时使用本地目标位置；运行前先在集成设置中完成节点配置并测试连接。
- **运行外部程序**：检查可执行文件、参数和工作目录，只运行可信程序或脚本。

### 文件伪装（Pro）

“文件伪装”把待处理文件追加到图片、音频、视频或自定义载体末尾，生成的载体文件仍可按原类型正常打开。它适合隐藏式封装和后续还原，不是加密功能；能够读取文件二进制内容的人仍可能发现附加数据，敏感内容应先加密。

选择 **文件伪装** 后，需要先选择操作：

- **创建伪装文件**：选择图片、音频、视频或自定义载体。载体可以是单个文件，也可以是一个目录；使用目录时可按随机、文件名或文件大小规则为待处理文件挑选载体。根据需要开启“完成后删除原文件”，并明确设置输出位置。
- **提取隐藏内容**：把已生成的伪装文件作为来源，提取其中附加的原始内容到目标位置；可选择提取成功后删除伪装文件。

:::caution[先保留原文件验证]
首次使用时不要开启删除选项。先用测试文件创建伪装文件，确认载体可以正常打开且隐藏内容能够完整提取，再决定是否删除原文件或伪装文件。文件伪装不能替代加密和备份。
:::

### 6. 设置高级选项并保存

展开 **高级选项** 可以使用以下设置：

- **启用/关闭**：关闭的任务仍会保留在列表中，但不会参与分组执行和自动运行。
- **创建桌面快捷方式**：为适用的任务创建桌面入口；该选项只在需要目标位置的操作中显示。
- **移动端来源**：启动局域网文件接收，把手机上传位置作为任务来源。使用前确认设备位于可信网络。
- <span class="fluent-icon fluent-icon--eye" aria-hidden="true"></span> **预览当前任务**：只扫描并显示匹配数量，同时提示不可用的源位置，不修改任何文件。

保存前至少要填写任务名称、分组、操作方式和匹配规则；AI 分类除外，其匹配规则由系统处理。保存普通任务后，任务默认只能手动运行，应用会询问是否前往“自动运行”添加触发器。

## 预览与手动执行

任务列表每行右侧都有 <span class="fluent-icon fluent-icon--edit" aria-hidden="true"></span> **编辑**、<span class="fluent-icon fluent-icon--delete" aria-hidden="true"></span> **删除** 和 <span class="fluent-icon fluent-icon--play" aria-hidden="true"></span> **运行** 按钮；双击任务行也会运行，但双击操作列或启用复选框不会触发执行。

手动运行时，EasyTidy Pro 会根据操作风险决定是否先预览：

- 移动、重命名、删除以及可能覆盖目标文件的复制等操作，默认先执行干运行，只统计匹配项，不修改文件。
- 标签、移除标签、AI 总结、文件快照、硬链接、软链接，以及不会覆盖文件的复制，可能直接执行。
- AI 分类会先生成分类计划，并让用户确认计划后再执行。

预览确认框会显示匹配数量和操作方式。勾选“不再显示危险操作预览”后，后续危险操作会直接执行；如需恢复预览，可在常规设置的文件处理选项中调整相关偏好。

执行结束后会显示处理数量。如果当前操作支持撤销，完成窗口会提供 <span class="fluent-icon fluent-icon--undo" aria-hidden="true"></span> **撤销刚才的操作**；也可以在任务列表右键菜单中使用 <span class="fluent-icon fluent-icon--undo" aria-hidden="true"></span> **撤销**。

- **非 Pro 用户**：支持临时撤销。撤销记录保存在内存中，可在同一次应用运行期间、操作完成后的 **1 小时内**使用；超过 1 小时或彻底退出 EasyTidy Pro 后，不应再依赖该记录恢复。
- **Pro 用户**：除运行期间的内存记录外，还可加载数据库中的持久化撤销历史，并配置历史保留天数。

并非所有操作都能撤销；如果文件已被其他程序再次移动、改名或删除，撤销也可能失败。撤销功能不能代替备份。

## 管理任务列表

任务表格在每行开头提供选择框，并显示任务名称、源位置、目标位置、是否创建快捷方式、启用状态和操作按钮。

- <span class="fluent-icon fluent-icon--checkbox" aria-hidden="true"></span> **启用/关闭**：直接点击“启用”列的复选框。
- <span class="fluent-icon fluent-icon--edit" aria-hidden="true"></span> **编辑**：修改规则、路径和操作参数；保存后相关文件监控会自动刷新，通常不需要重启。
- <span class="fluent-icon fluent-icon--delete" aria-hidden="true"></span> **删除**：单条删除前会要求确认；删除任务也会解除它的文件监控配置。
- <span class="fluent-icon fluent-icon--copy" aria-hidden="true"></span> **复制**：选中任务后右键选择“复制”，快速创建带时间戳名称的副本。
- **批量移动或删除**：勾选每行开头的选择框后，使用列表上方出现的批量操作栏，将任务移动到其他分组，或一次删除全部已选任务。
- <span class="fluent-icon fluent-icon--share" aria-hidden="true"></span> **分享规则**：选中任务后右键导出 `.etrule` 文件。
- <span class="fluent-icon fluent-icon--sync" aria-hidden="true"></span> **刷新**：重新从数据库加载任务列表。

### 调整执行顺序

拖动任务行可以调整顺序，新的顺序会立即保存。任务按分组批量执行时会使用已保存的顺序；这只是先后顺序，不会建立任务依赖。

新建任务会添加到当前列表末尾。列表不再提供数据库 ID/顺序编号的切换按钮，执行顺序以当前拖动排序为准。

如果多个任务会匹配同一个文件，顺序会直接影响结果。例如第一条任务移动文件后，后面的任务可能不再找到它。建议让规则互斥，或先用复制验证完整流程。

### 使用任务分组

页面顶部的分组选择器可以：

- 筛选当前分组的任务；
- 点击 <span class="fluent-icon fluent-icon--play" aria-hidden="true"></span> **执行分组**，按顺序运行该组中所有已启用任务；
- 将某个分组设为默认显示分组；
- 点击 **分组管理**，在同一个弹窗中新增、重命名或删除自定义分组。

“全部分组”和“未分组”是始终保留的内置项，不能重命名或删除。“全部分组”用于查看所有任务；没有指定自定义分组的新任务会进入“未分组”。

:::note[删除分组不会删除任务]
删除自定义分组后，组内任务会自动移动到“未分组”，任务定义和对应配置会继续保留。批量删除任务是另一项独立操作，确认对话框中应再次核对选择数量。
:::

分组执行会先运行普通任务，再逐个处理需要计划预览的 AI 分类任务。批量执行前应分别验证每条任务，尤其要检查前一条任务的输出是否会成为后一条任务的输入。

## 导入、导出与分享

页面顶部提供两套用途不同的数据交换方式。

### Excel 批量维护

导出菜单包含：

- <span class="fluent-icon fluent-icon--document-table" aria-hidden="true"></span> **导出模板**：生成可填写的 `.xlsx` 模板，适合一次创建多条任务。
- <span class="fluent-icon fluent-icon--export" aria-hidden="true"></span> **导出任务**：把当前列表中的任务导出为 `.xlsx`，可修改后重新导入。
- <span class="fluent-icon fluent-icon--import" aria-hidden="true"></span> **导入**：读取 `.xlsx`。模板文件中的有效行会创建新任务；由“导出任务”生成且保留任务 ID 的行会更新对应任务，没有 ID 的行会新建任务。

Excel 导入/导出依赖“文档内容提取”组件。组件未安装时，应用会先询问是否下载并启用。导入出现部分错误时，应用会生成错误文件；请按行号修正后再次导入，不要忽略无效路径或操作参数。

### `.etrule` 单条规则分享

选中一条任务，打开导出菜单或右键菜单，选择 <span class="fluent-icon fluent-icon--share" aria-hidden="true"></span> **分享规则** 即可生成 `.etrule`。导入 `.etrule` 时，应用只接受“整理任务”类型的分享包；绝对路径会尽量转换为路径别名，无法解析的自定义别名会要求在本机重新指定。

`.etrule` 适合分享单条任务定义，Excel 更适合批量维护。两者都不会替你创建自动运行触发器，导入后应先检查路径、规则、操作参数和授权状态，再手动预览。

:::caution[只导入可信文件]
分享文件可能包含本地路径、网络地址、外部程序参数或云端配置引用。导入来源不明的任务可能导致文件被移动、覆盖、上传或删除。
:::

## 配置自动运行

新建或导入任务后，它不会仅因为“启用”就自动执行。需要自动整理时：

1. 先手动预览并成功执行一次任务。
2. 保存后在提示框中选择前往设置，或进入主导航的 **自动运行**。
3. 选择任务，并添加文件变更、启动、固定间隔、CRON 计划或关闭触发器。
4. 保存并使用“预览结果”验证。

关闭主窗口并最小化到托盘时，自动任务仍可工作；从托盘彻底退出 EasyTidy Pro 后，文件监控和定时调度不会继续运行。完整说明请参阅[自动化配置](/zh-cn/guide/automation/)。

## 常见问题

### 保存按钮没有反应

检查任务名称、分组、操作方式和文件匹配规则是否已填写，并留意输入框下方的校验信息。普通任务缺少匹配规则时不能保存；AI 分类会自动使用匹配规则。

### 预览显示没有匹配文件

检查源位置是否存在、是否需要扫描子文件夹、扩展名是否包含点号，以及是否误开了正则模式。基础规则和高级筛选同时使用时，也可能因为条件过严而没有结果。

### 任务已启用，但没有自动运行

“启用”只表示任务允许执行，不等于已经配置触发器。进入 **自动运行** 检查任务卡和触发方式，并确认应用仍在托盘运行、没有暂停全部任务。

### 分组执行漏掉了某些任务

分组执行只运行该分组中已启用的任务。检查任务是否被关闭、是否分到了其他组，以及前面的任务是否已经移动或删除了后续任务需要处理的文件。

### 复制或移动后出现同名文件

编辑任务并检查同名文件处理策略。首次验证建议选择“跳过”或自动追加序号；确认来源和目标正确后，再考虑覆盖策略。

### 执行后还能恢复吗？

如果完成窗口显示“撤销刚才的操作”，可以立即尝试撤销；回收站操作也可以从 Windows 回收站恢复。非 Pro 用户的临时撤销仅在同一次应用运行期间有效，并且记录最多保留 1 小时；Pro 用户可使用持久化撤销历史。永久删除、外部程序、云端操作以及文件状态已经再次变化的情况不保证可撤销，因此重要数据必须另行备份。

更多运行记录和错误详情可在[运行日志](/zh-cn/guide/logs/)中查看。
