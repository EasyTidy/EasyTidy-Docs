EasyTidy Pro 可以把云端存储作为整理任务的目标或来源，也可以将部分存储挂载为 Windows 盘符。所有入口均位于 **集成** 页面；配置完成后，在新建或编辑规则时选择 **云存储传输** 即可使用。

![云存储集成页面概览](/images/zh/cloud-storage-integrations-overview.png)

## 支持范围

| 类型 | 上传/取回 | 多配置 | 盘符挂载 | 应用备份 |
| --- | --- | --- | --- | --- |
| WebDAV | 支持 | 支持 | 支持 | 支持 |
| S3 兼容存储 | 支持 | 支持 | 支持 | 不支持 |
| 百度网盘 | 支持 | 支持 | 不支持 | 不支持 |
| 123 云盘 | 支持 | 支持 | 暂不支持 | 不支持 |

:::note
“应用备份”指备份 EasyTidy Pro 的配置和数据，不是备份任意文件。当前远程应用备份仅支持 WebDAV。
:::

## WebDAV

WebDAV 分为两个用途：

- **文件整理上传**：可添加多个账号、设置别名和默认账号，并可挂载盘符。
- **应用备份**：单独配置备份端点，供手动/自动备份及恢复使用。

添加文件整理账号时，需要填写服务器 URL、端口、用户名、密码和远程路径。URL 必须以 `http://` 或 `https://` 开头；远程路径建议使用以 `/` 开头的目录，例如 `/EasyTidyPro_UploadFiles`。

![WebDAV 上传账号配置](/images/zh/cloud-storage-webdav-account.png)

如果同一服务用于整理上传和应用备份，仍建议为两种用途设置不同的远程目录，避免普通文件与备份包混在一起。

### WebDAV 应用备份

1. 在 **集成 → WebDAV → 应用备份** 中配置账号和远程路径。
2. 前往 **设置 → 常规 → 备份设置**，选择 WebDAV。
3. 可立即执行备份，也可启用自动备份并设置间隔和最大保留数量。
4. 恢复时，程序会按时间列出远端可用备份；选择版本后再执行恢复。

![选择 WebDAV 备份版本](/images/zh/cloud-storage-webdav-restore-version.webp)

恢复会覆盖当前应用数据。建议先创建一次本地备份，并确认远端备份的时间和来源。

## S3 兼容存储

S3 集成支持多个存储桶配置，可以设置默认项。当前提供以下服务类型：

- 通用 S3 兼容服务，例如 AWS S3；
- 七牛云存储；
- 腾讯云 COS；
- 自建 S3 兼容服务，例如 OpenList、MinIO、Garage。

通常需要填写：

- **Access Key / Secret Key**：存储服务提供的访问凭据；
- **Bucket**：存储桶名称；
- **Region**：区域，服务商没有特殊要求时默认值为 `us-east-1`；
- **Endpoint**：第三方或自建服务的 S3 API 地址，AWS S3 通常可以留空；
- **路径前缀**：文件在存储桶中的目标目录。

请使用 S3 API Endpoint，不要填写对象存储控制台网址或公开下载域名。建议为凭据仅授予目标存储桶所需的列举、读取、写入和删除权限。

![S3 存储桶配置](/images/zh/cloud-storage-s3-bucket.png)

## 百度网盘

百度网盘集成使用开放平台应用凭据和账号授权，可保存多个配置并指定默认账号。配置时需要准备 `App Key`、`Secret Key`，然后按页面提示完成账号授权；路径前缀用于指定应用目录下的目标位置。

授权令牌可能过期或被撤销。出现鉴权失败时，请先回到集成页面重新授权，再测试任务。

![百度网盘账号授权与路径配置](/images/zh/cloud-storage-baidu-authorization.png)

## 123 云盘

:::caution[需要自备 Key]
123 云盘集成不提供公共 Key。你必须自行在 **123 云盘开放平台**申请应用，取得 `Client ID` 和 `Client Secret` 后才能使用。EasyTidy Pro 不内置、不共享，也不代为申请这些凭据。
:::

配置步骤：

1. 在 123 云盘开放平台创建应用并开通所需 API 权限。
2. 打开 **集成 → 123 云盘**，新增配置。
3. 填写别名、`Client ID`、`Client Secret` 和路径前缀。
4. 选择文件冲突策略，保存配置；存在多个账号时，可指定默认项。
5. 创建整理规则，选择 **云存储传输 → 123 云盘**，再选择对应配置。

![123 云盘 Client ID 与 Client Secret 配置](/images/zh/cloud-storage-pan123-key.png)

路径前缀为空时，程序使用默认目录 `/EasyTidyPro_UploadFiles`。123 云盘目前不能挂载为 Windows 盘符，需要等待官方提供可用的 WebDAV 能力。

请勿在问题反馈、截图或日志中公开 `Client Secret`。若凭据已经泄露，应立即到开放平台重置。

## 在整理任务中使用

1. 先在 **集成** 页面完成至少一个云存储配置。
2. 新建或编辑整理规则，将操作方式设为 **云存储传输**。
3. 选择上传或取回、存储类型和具体配置。
4. 按需填写任务路径前缀。任务中的路径会与集成配置的基础路径组合使用。
5. 保存后先用少量测试文件运行，确认目录和冲突处理符合预期。

![整理规则中的云存储传输配置](/images/zh/cloud-storage-rule-transfer.png)

同一类型存在多个配置时，规则会记录所选配置；未明确选择时使用默认项。删除正在被规则引用的配置后，应重新编辑相关规则。

## 文件冲突

各集成可以设置文件重名时的处理方式；未单独设置时使用应用的全局文件冲突策略。正式运行前，建议用同名测试文件确认覆盖、跳过或重命名行为，特别是自动执行的规则。

## 盘符挂载

WebDAV 和 S3 配置可以挂载为 Windows 盘符。首次启用时，程序会准备 rclone 和 WinFsp 运行环境；完成后选择未占用的盘符即可。

![云存储盘符挂载与缓存状态](/images/zh/cloud-storage-drive-mount.webp)

- 挂载依赖网络连接，云端文件的响应速度通常低于本地磁盘。
- 挂载会使用本地缓存，可在集成页面查看或清理缓存。
- 可在设置中启用“启动时自动挂载已配置盘符”。
- 盘符被占用、WinFsp 未正确安装或凭据失效时，挂载会失败。

## 常见问题

### 连接成功但无法上传

检查远程路径是否可写、账号是否具有创建目录和上传文件的权限，以及服务端配额是否充足。S3 还需确认 Bucket、Region 和 Endpoint 相互匹配。

### 提示 401、403 或鉴权失败

重新检查访问凭据。百度网盘可尝试重新授权；123 云盘需确认 `Client ID`、`Client Secret` 来自同一个有效应用，并且应用具有所需权限。

### 文件上传到了意外目录

同时检查集成配置和整理规则中的路径前缀。建议统一使用 `/目录名` 的形式，不要把服务器地址或 Bucket 名写入路径前缀。

### WebDAV 恢复列表为空

确认当前配置与创建备份时使用的是同一个服务器和远程目录，并确认账号具有列出及下载该目录文件的权限。
