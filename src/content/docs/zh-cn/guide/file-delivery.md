---
title: 文件传输
description: 在同一局域网中从手机或其他设备向 EasyTidy Pro 上传文件，并按需关联整理任务或工作流。
---

“文件传输”用于从手机、平板或同一局域网中的其他设备向当前电脑上传文件。EasyTidy Pro 会在电脑上启动一个本地 HTTP 接收服务，其他设备通过浏览器打开访问地址，选择文件并上传到接收目录。

该功能当前的主要方向是 **其他设备 → 当前电脑**，不是从电脑主动向手机发送文件。文件直接在局域网内传输，不需要先上传到 EasyTidy Pro 的云端；电脑上的 EasyTidy Pro 必须保持运行。

:::caution[仅在可信局域网中开启]
接收服务不要求密码，也没有独立的设备授权。连接到同一 Wi-Fi 或网络的任何设备，只要知道页面显示的地址，就可以向接收目录上传文件。传输使用 HTTP，不提供端到端加密。不要在公司、学校、酒店、咖啡店等公共网络中开启，也不要在路由器上配置端口映射或把服务暴露到互联网。
:::

## 功能与版本差异

| 能力 | 免费版 | Pro |
| --- | :---: | :---: |
| 从同一局域网设备接收文件 | 支持 | 支持 |
| 一次选择并上传多个文件 | 支持 | 支持 |
| 关联普通整理任务 | 支持，上传后手动整理 | 支持，上传后自动整理 |
| 关联高级流程 | 不支持 | 支持，上传后自动执行 |
| 修改接收目录 | 不支持 | 支持 |
| 上传记录 | 保留 7 天 | 永久保留，可删除单条或清空 |

默认模式是 **只接收，不整理**。建议先完成一次只接收测试，确认网络、目录和同名文件行为都符合预期，再关联整理任务。

## 第一次接收文件

### 1. 打开文件传输页面

1. 启动 EasyTidy Pro。
2. 进入 **集成设置**。
3. 打开 **文件传输**。
4. 确认电脑与发送设备连接到同一个可信 Wi-Fi 或局域网。

页面包含接收开关、接收目录、关联任务、安全提示、传输端口、上传记录和高级选项。

![文件传输页面总览](/images/zh/file-delivery-overview.png)

### 2. 检查接收目录

免费版默认使用桌面下的 `MobileSync` 文件夹：

```text
桌面\MobileSync
```

该目录同时对应内置路径别名 `%MobileSync%`。Pro 用户可以点击 **修改目录** 选择其他文件夹；修改结果会作为 `%MobileSync%` 的自定义覆盖持久保存。

:::note[优先在任务中使用路径别名]
如果准备让上传文件自动整理，建议把任务或流程的来源写成 `%MobileSync%`，不要直接写死旧的绝对路径。这样 Pro 用户修改接收目录后，引用该别名的规则会自动使用新位置。
:::

### 3. 启用文件接收

打开 **启用文件接收**。启动成功后，页面会显示：

- 当前局域网访问地址，例如 `http://192.168.1.20:9996`；
- 与该地址对应的二维码；
- 当前接收目录。

在此页面打开接收开关后，选择会被记住。下次启动 EasyTidy Pro 时，接收服务也会自动启动，直到你主动关闭开关。离开该页面或把主窗口最小化到托盘不会停止基础文件接收；彻底退出 EasyTidy Pro 会停止服务。

:::note[自动整理时保持本页打开]
当前版本由“文件传输”页面处理上传记录和关联任务的自动触发。只接收文件时可以离开该页面；需要生成上传记录、执行免费版手动整理或让 Pro 自动整理时，请在上传完成前保持“文件传输”页面打开。
:::

服务空闲时会进入低占用等待状态。其他设备第一次打开地址时，可能短暂看到“正在唤醒上传服务”，页面会自动刷新，通常不需要重复扫码。

### 4. 在手机或其他设备上打开上传页

在发送设备上执行以下任一操作：

- 使用相机或扫码工具扫描二维码；
- 在浏览器地址栏输入电脑端显示的完整访问地址。

打开后会看到 **文件上传助手**。如果浏览器提示无法访问，不要改用移动数据网络；先确认两台设备仍连接到同一个局域网。

<!-- 图片要求：展示手机浏览器中的“文件上传助手”初始页面，清楚显示“选择文件”和“上传配置”按钮。浏览器地址栏使用示例局域网地址，截图不得包含真实 Wi-Fi 名称、通知内容、联系人、相册缩略图或设备标识。建议使用 9:19.5 竖图。 -->
![手机端文件上传助手](/images/zh/file-delivery-mobile-home.jpg)

### 5. 选择并上传文件

1. 点击 **选择文件**，在系统文件选择器中选择一个或多个文件。
2. 在文件列表中核对文件名、大小、总数量和总大小。
3. 不需要上传的项目可以单独移除，也可以勾选后批量移除。
4. 点击添加按钮可以继续选择更多文件。
5. 点击 **开始上传**，等待进度达到 100% 并出现“上传成功”。

页面本身没有设置固定的文件数量或请求体大小上限，并使用流式方式写入电脑；实际可上传规模仍受手机浏览器内存、网络稳定性、电脑磁盘空间和文件系统限制。传输大量或超大文件时，建议拆成多批，并保持浏览器在前台。

![选择文件与上传进度](/images/zh/file-delivery-mobile-upload.jpg)

### 6. 在电脑上确认结果

上传成功后，文件先写入当前接收目录。EasyTidy Pro 不会覆盖已有同名文件；如果 `报告.pdf` 已存在，新文件会依次保存为 `报告 (1).pdf`、`报告 (2).pdf` 等。

页面下方的上传记录会显示文件名、上传时间、关联任务和“已整理”状态。列表当前加载最近 **200 条**记录。

## 关联整理任务或流程

文件传输页面可以选择以下三种处理方式：

| 选项 | 上传后的行为 |
| --- | --- |
| **只接收，不整理** | 文件保留在接收目录，不运行任务 |
| **整理任务** | 使用已保存的一条普通整理任务处理接收目录中的文件 |
| **整理流程** | 使用已保存的一条高级流程处理文件，仅 Pro 可选 |

### 先准备正确的来源路径

关联任务并不会临时改写该任务的来源。上传完成后，EasyTidy Pro 运行的是已保存的任务或流程，因此它的来源必须指向当前接收目录。

推荐按以下方式准备普通整理任务：

1. 进入 **文件整理 → 整理任务**，新建或编辑一条任务。
2. 将来源位置设置为 `%MobileSync%`。
3. 配置文件规则、筛选条件、操作方式和目标位置。
4. 先在接收目录放入少量测试文件，手动预览并执行一次。
5. 返回 **集成设置 → 文件传输**，选择 **整理任务**，再从列表中选择刚才验证过的任务。

高级流程同样需要把来源指向 `%MobileSync%` 或当前接收目录，并先单独预览。任务和流程的完整配置方式请参阅[整理任务](/zh-cn/guide/task/)和[高级流程](/zh-cn/guide/workflow/)。

:::caution[任务会扫描其已保存来源]
关联整理使用任务自身的来源和规则，不是只处理上传记录中当前勾选的几项。如果接收目录里还留有以前上传或手动放入的文件，它们也可能被匹配。涉及移动、覆盖、删除、外部程序或云端传输时，应使用独立测试目录并保持危险操作预览。
:::

### 免费版：手动整理

免费版选择普通整理任务后，上传只负责保存文件，不会自动执行。确认文件已经完整到达接收目录后，点击页面中的 **手动整理**。

手动整理会运行所选任务。任务未启用、来源不是接收目录、规则没有匹配、目标不可写或文件仍被占用时，可能没有得到预期结果。请到[运行日志](/zh-cn/guide/logs/)核对实际执行情况。

### Pro：上传后自动整理

Pro 用户选择普通整理任务或高级流程后，上传完成事件会自动触发所选配置，不需要再点击“手动整理”。切换回 **只接收，不整理** 即可停止自动触发。

自动整理适合来源明确、规则稳定且已经验证的场景。第一次配置时建议使用“复制”而不是“移动”或“永久删除”，确认目标目录和规则正确后再调整操作方式。

当前版本需要保持“文件传输”页面打开，才能由该页面接收上传完成事件并触发自动整理。页面关闭后，接收服务仍可能继续保存文件，但不要依赖关联任务在后台自动执行。

:::note[“已整理”不是完整执行报告]
上传记录用于追踪文件投递和关联状态，不能替代任务执行日志。即使记录显示“已整理”，仍应通过目标目录和运行日志确认任务是否真正匹配、执行成功以及处理了多少文件。
:::

## 手机端上传配置

点击手机上传页中的 **上传配置** 可以调整以下内容：

- **上传接口地址**：默认是 `/api/upload`。普通使用不要修改；错误地址会导致上传失败。
- **原图**：按原始内容上传，不做浏览器端转换，适合文档、归档图片、透明图片和需要保留原始质量的文件。
- **压缩图**：仅对浏览器识别为图片的文件进行客户端压缩；最长边会限制在 1920 像素以内，并按 JPEG 编码输出。
- **压缩质量**：范围为 `0.1`～`0.9`，默认 `0.8`。数值越低，通常文件越小，画质损失越明显。

压缩发生在发送设备的浏览器中，会增加手机的内存和处理开销。重要照片、带透明通道的图片、需要保留元数据或原始格式的素材应选择 **原图**。

电脑端页面底部的 **高级选项（Pro）** 当前只用于提示这些配置位于手机上传页面，本身没有独立参数。实际上传行为以发送设备浏览器中的“上传配置”为准。

## 接收目录、端口与服务状态

### 修改接收目录（Pro）

点击接收目录卡片中的 **修改目录**，选择一个当前用户可写、磁盘空间充足且不会被其他自动化规则循环监控的位置。修改后 `%MobileSync%` 会解析到新目录；如果已有任务使用绝对路径，需要手动同步修改。

如果接收服务正在运行，修改目录后应重新确认页面显示的新路径，再上传一个小文件验证。目录不存在时，服务会在首次上传时尝试创建；没有写入权限会导致上传失败。

### 修改传输端口

默认端口是 `9996`，允许范围是 `1`～`65535`。只有在默认端口被其他程序占用或网络策略要求使用其他端口时才需要修改。

为确保新端口生效，建议按以下顺序操作：

1. 关闭 **启用文件接收**。
2. 修改传输端口，优先选择大于 `1024` 且未被占用的端口。
3. 重新打开接收开关。
4. 使用页面重新生成的地址或二维码访问，不要继续使用旧书签。

Windows 防火墙可能在首次启用时询问网络访问权限。只允许当前可信的“专用网络”，不要为公共网络开放。公司设备上的安全策略可能会阻止监听端口，此时需要遵循组织的网络规定。

## 上传记录

每个成功写入接收目录的文件都会创建一条记录。记录包含：

- 文件名；
- 上传时间；
- 当时关联的任务或流程名称；
- 是否已标记为整理。

免费版记录保留 7 天，打开页面时会清理过期数据。Pro 记录永久保存，并提供单条删除和 **清空记录**。

删除上传记录只会删除数据库中的记录，不会删除接收目录中的实际文件，也不会撤销已经执行的整理操作。需要恢复文件时，应根据具体操作使用撤销、回收站或备份。

## 安全建议

- 只在家庭网络等可信局域网中启用，用完立即关闭接收开关。
- 不要把二维码、访问地址或局域网 IP 发布到聊天群、工单或公开截图中。
- 不要在路由器配置端口转发，也不要通过公网隧道暴露该 HTTP 服务。
- 接收目录不要设为系统目录、程序安装目录、云盘自动执行目录或含敏感文件的目录。
- 自动整理任务应避免永久删除、无条件覆盖、上传到云端或运行不可信脚本。
- 定期检查接收目录、上传记录和运行日志，及时清理未知文件。
- 对来源不明的文档、压缩包和可执行文件先进行安全检查，不要仅因为来自同一 Wi-Fi 就直接打开。

## 常见问题

### 扫码后无法打开页面

依次检查：

1. EasyTidy Pro 是否仍在运行，接收开关是否开启；
2. 手机和电脑是否连接到同一个局域网，而不是一个使用 Wi-Fi、另一个使用移动数据；
3. 当前二维码和地址是否为页面最新显示的内容；
4. Windows 防火墙是否允许 EasyTidy Pro 访问专用网络；
5. 路由器是否开启了访客网络隔离或 AP 隔离；
6. VPN、代理或安全软件是否阻止了局域网访问。

服务从空闲状态唤醒时可能需要短暂等待。如果页面显示正在唤醒，让浏览器自动刷新；持续失败时，关闭接收开关后重新开启。

### 打开开关后提示启动失败

常见原因是端口被占用、端口值无效或安全软件阻止监听。关闭接收服务，改用另一个大于 `1024` 的空闲端口后重新开启。如果仍然失败，请查看应用日志，不要通过关闭全部防火墙长期绕过问题。

### 手机显示上传成功，但电脑上找不到文件

先检查页面显示的当前接收目录，再查看上传记录。如果关联了自动整理任务，文件可能已经移动、重命名或删除；到运行日志和任务目标目录中继续查找。同名文件会自动追加 `(1)`、`(2)` 等序号。

### 上传后没有自动整理

检查以下项目：

- 当前是否为 Pro，并且关联方式不是“只接收，不整理”；
- 上传时“文件传输”页面是否保持打开；
- 是否已经选择有效且启用的任务或流程；
- 任务或流程的来源是否为 `%MobileSync%` 或当前接收目录；
- 文件是否满足规则和筛选条件；
- 目标目录、组件、授权或外部服务是否可用。

免费版不会自动整理，需要点击 **手动整理**。

### 点击手动整理后没有移动文件

“手动整理”运行所选任务的已保存配置。检查任务来源、匹配规则、启用状态和目标位置，并先在整理任务页面单独预览。空文件或没有匹配规则的文件会留在接收目录。

### 大文件上传中断或长时间没有进度

保持发送设备浏览器在前台，关闭省电或锁屏导致的网络暂停，并确认电脑磁盘空间充足。弱 Wi-Fi 下建议靠近路由器或拆成较小批次。中断后重新上传时，已经完整保存的同名文件不会被覆盖，新文件会追加序号。

### 为什么重新启动应用后接收服务又开启了

在文件传输页面开启接收会持久保存该选择，这是预期行为。返回该页面关闭 **启用文件接收**，后续启动时就不会再自动开启。

相关规则配置请参阅[整理任务](/zh-cn/guide/task/)、[高级流程](/zh-cn/guide/workflow/)和[路径别名](/zh-cn/guide/rules/)，执行错误和自动整理结果可在[运行日志](/zh-cn/guide/logs/)中查看。
